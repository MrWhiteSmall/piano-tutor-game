# 琴屿 · Piano, little by little

一个给零基础学习者的钢琴入门网页项目。保留 A0—C8 的完整 88 键地图，电脑键盘只映射常用音区，随曲子的版本逐步变化。现有 5 首曲子，每首 6 版，共 30 关：同一旋律从三个音的简化轮廓，成长为带时值、奏法与左手伴奏的入门节选。包含真实可弹奏练习、前后试听、简短理论、指法提示与乐理小测。

## 启动

需要 Node.js 20.19+ 或 22.12+（推荐当前 LTS）。

```sh
git clone git@gitee.com:lushengjie/piano-tutor-game.git
cd piano-tutor-game
npm install
npm run dev
```

打开终端显示的本机地址。默认端口 5188，被占用时 Vite 自动选择下一个端口。已有本地项目可直接在项目目录运行 `npm run dev`。

```sh
npm run build       # 输出 dist/，可部署到静态托管
npm run preview     # 预览构建产物
npm test            # 课程与判定逻辑测试
PIANO_URL=http://127.0.0.1:5190 node tests/browser.mjs
```

浏览器测试需要本机已安装 Google Chrome。截图生成于 `.local/`，不提交版本库。Google Fonts 仅用于字体美化，加载失败时使用本地字体，不影响弹奏。应用运行不调用模型服务，不需要 API Key。

## 为什么不把 88 个音都绑定到电脑按键

88 键的价值在于音域与空间关系，初学者不需要同时操作 88 个音。课程始终显示全景，同时放大当前音区。右手两排的相对位置保持稳定。每首前两版，右手整体映射到 C3—C4；第 3 版起移到 C4—C5，让玩家听到同一句高一个八度的变化。界面会同步显示当前实际音名，MIDI 用户须在实体键盘上移动手位。自由琴房默认映射如下：

| 用途 | 电脑按键 | 默认音高 |
| --- | --- | --- |
| 右手白键 | A S D F G H J K | C4 D4 E4 F4 G4 A4 B4 C5 |
| 右手黑键 | W E T Y U | C♯4 D♯4 F♯4 G♯4 A♯4 |
| 左手白键 | Z X C V B N M | C3 D3 E3 F3 G3 A3 B3 |
| 开始 / 暂停 | 空格 | 输入框等控件聚焦时保留其默认操作 |
| 自由琴房换八度 | [ / ] 或页面 − / + | 两排按键同时移调 |

自由琴房可点击全景中的任意音，涵盖完整 88 键。触屏支持多指；部分电脑键盘的组合键存在硬件冲突，双手和弦更适合使用 MIDI 键盘。

## 同一首曲子，六次成长

课程包含《小星星》《欢乐颂》《两只老虎》《玛丽有只小羊羔》《铃儿响叮当》的入门旋律节选。各自占六关。轮廓版会替换部分音并简化时值，不代表原曲完整旋律；休止和伴奏含练习用编配。

| 版本 | 新变化 | 暂时保持的部分 |
| --- | --- | --- |
| 1 · 认出轮廓 | C3 附近只用三个音，按提示弹顺序 | 不考节奏和保持时长 |
| 2 · 补全旋律 | 补回原本的旋律音 | 同一句、同音区、均匀时值 |
| 3 · 让旋律亮起来 | 每个音升高一个八度 | 旋律音之间的关系、时值、速度 |
| 4 · 给句子留一点时间 | 加入长短音，部分曲子含休止 | 音高和音区 |
| 5 · 试出自己的语气 | 选择轻柔连贯或轻快短促 | 音高、音符落键时机 |
| 6 · 给旋律一个陪伴 | 一些落键处加入左手低音 | 上一版旋律、时值和玩家通过时选择的表达 |

“试听版本”可选择同一首曲子的全部六版，未解锁的版本也可以听。“前后对比”播放所选版与上一版的同一句节选，用同样速度；选择第 1 版时对比第 1、2 版。“试听这版”单独听所选版，“先听示范”演奏当前练习关的全部节选并跟随乐谱提示。切换页面、练习或停止时会取消全部待播放音符。

每关弹奏结束且准确率达到 80%，进入该关乐理小测，答对后保存通过状态并解锁下一关。学习手册保留最初的 30 个基础乐理主题，可随时查阅。

每首前 3 版只考音高顺序；第 4 版起提供四拍预备拍并检查节奏、时值；第 5 版起加入所选奏法的离键检查。第一个落键建立时间基准，之后依据乐谱拍数计算，包含休止。时机容差为 ±0.48 拍。普通时值下限为 55%，连贯为 72%，上限均为标记时长加 0.6 拍；短促音应在标记时长的 12%—50% 之间离键，下一音仍按原节拍进入。长音在两种表达中都保持。和弦各音需在 200 ms 内落下且同时按住。

两种表达都会实际改变示范的离键时机和强度，并按相应规则判定；电脑按键和触屏本身没有钢琴式力度感应，所以不根据按字母的力气评分。MIDI 速度值可以影响响度，也不参与本轮通关判分。当前的“连贯”是入门的保持时长练习，没有教授完整的钢琴连奏指法、声部独立或踏板。

新路线使用单独的 `qinyu-song-journey-v2` 进度键。原 `qinyu-progress` 数据保留，但不会把旧课程的通过记录直接认作新关卡通过。

准确率 = 已完成音组 ÷（已完成音组 + 错误数）。错音、节奏偏差、时值不符和和弦不齐会计错，允许修正继续。该数值是本应用的入门练习指标，不能代替教师对钢琴演奏水平的评定。

## 技术与边界

- 原生 JavaScript、CSS、SVG 与 Vite；Web Audio 实时合成有衰减包络的音色，可调音量、示范和节拍器。当前并非钢琴采样音源。
- 学习进度存于当前浏览器的 `localStorage`，刷新后继续；不跨设备同步，也没有服务端账号。浏览器禁用存储时退回本次会话内存。
- Web MIDI 接收标准 Note On / Note Off 与输入力度；支持 USB MIDI 键盘热插拔。需浏览器授权，推荐桌面 Chrome / Edge；不支持时仍可使用电脑按键或触屏。真实硬件连接需在有设备的环境进一步验证。
- 网页适合训练基础乐理、音名、读谱、节奏和双手任务关系。电脑按键的形状与真实钢琴不同，**手型、触键、力度控制、穿指、踏板与空间跨度需要实体琴练习**。30 关完成代表走完入门路径，不保证独立掌握钢琴演奏。
- 当前不分析麦克风输入，不自动识别普通原声钢琴，也不教授完整力度标记、调号体系、踏板与进阶演奏法。

新曲目与版本在 `src/journey.js`，原乐理手册与琴键工具在 `src/curriculum.js`，计分逻辑在 `src/engine.js`，声音在 `src/audio.js`，界面与输入在 `src/main.js`。后续可以接入采样音源、教师审核课程，以及更多实体琴练习任务。
